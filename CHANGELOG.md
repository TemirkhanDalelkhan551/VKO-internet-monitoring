# История изменений

## 19.09.2026 — диагностика, зависимости и восстановление

- Работа второго компьютера принята пользователем без требования повторной полевой проверки; связанные пункты чек-листа закрыты.
- В CI добавлен аудит прямых и транзитивных NuGet-зависимостей; Dependabot еженедельно проверяет NuGet и GitHub Actions.
- Резервные копии получили ограниченную ротацию; отдельный скрипт восстанавливает dump во временную базу, сверяет десять основных таблиц и удаляет тестовую базу.
- Добавлен диагностический ZIP: состояние Windows/службы, размеры очереди и журналов, очищенная конфигурация и последние строки логов без `device-token.dat` и содержимого очереди.
- Готовность по 183 пунктам пересчитана с 85% до 86%.

## 19.09.2026 — быстрый эксплуатационный контур

- Добавлен GitHub Actions CI для Release-сборки, 220 .NET-тестов, 25 JS-тестов и синтаксиса PowerShell при каждом push/pull request.
- Сборка установщика теперь проверяет имя, версию, размер, SHA-256 и статус подписи и создаёт `.sha256`-манифест.
- Задокументировано тихое обновление уже активированного агента; первичная бездиалоговая активация оставлена открытым требованием.
- Добавлены скрипт измерения ресурсов Windows-службы и проверяемое custom-format резервное копирование локальной PostgreSQL.
- Добавлена единая эксплуатационная инструкция; готовность по 183 пунктам пересчитана с 84% до 85%.

## 19.09.2026 — тестовый замер по запросу, версия 1.2.1

- В локальную панель добавлена команда «Проверить интернет сейчас» для полного измерения пяти метрик без ожидания ближайшего окна расписания.
- Панель передаёт запрос через атомарный файл-сигнал в защищённом каталоге данных; токен не копируется, второй экземпляр агента не запускается.
- Windows-служба потребляет запрос однократно и использует обычные ограничения нагрузки, очередь, повторы и серверную идемпотентность `EventId`.
- Установка и активация EXE 1.1.0 на втором физическом компьютере подтверждены пользователем.
- Полевой статус подтвердил рабочие облачный API, устройство и heartbeat. Журнал показал штатную остановку службы установщиком 1.2.0 без последующего запуска; ручной `Start-Service` вернул службу в `Running` без ошибок приложения.
- По полевому журналу исправлено обновление 1.2.0, оставлявшее ранее запущенную службу в состоянии `Stopped`: установщик запоминает исходное состояние и обязательно восстанавливает `Running`.
- Если служба всё же остановлена, кнопка тестового замера пытается запустить её автоматически и сообщает отдельную ошибку, если процесс сразу завершился.
- Диагностика различает состояния «остановлена» и «не удалось проверить».
- Проверены 220 .NET-тестов и 25 веб-тестов; Release-сборка завершена без ошибок и предупреждений.
- После полевого исправления повторно пройдены 299 изолированных интеграционных проверок и Linux Docker-сборка API. Render readiness и PostgreSQL имеют статус `Healthy`.
- Собран EXE 1.2.1: 37 264 431 байт, SHA-256 `3667EB6175E03CFAC2CEEDFA9549CD14E1BDC5E5C68C4ADF101E8E592CBAC0CD`. Цифровая подпись пока отсутствует.

## 19.09.2026 — удобная и безопасная активация агента

- Мастер переведён на два шага: сначала проверяет Windows, права, установленную службу, место на диске, готовность API, TLS, малые Download/Upload-запросы и одноразовый код, затем показывает школу, линию, поставщика, тип подключения и срок кода.
- Код не расходуется при предварительной проверке; активация выполняется только после явного подтверждения привязки.
- Рабочий адрес Render встроен в конфигурацию установщика и сохраняется после успешной активации; ручное поле остаётся для локальных и отдельных развёртываний.
- Добавлен API предварительной проверки с тем же rate limit, хэшированным кодом и отказом для неверного, истёкшего, использованного или неправильно сформированного кода.
- Уточнены сообщения о неготовом/долго запускающемся сервере, сети, TLS, превышении числа попыток и истёкшем коде.
- После запуска службы мастер до 15 секунд ждёт первый heartbeat и сообщает, подтверждена ли связь с сервером.
- Локальная панель копирует диагностический отчёт с версией, Windows, службой, сервером, устройством, последней связью и ошибкой; токен и другие секреты не включаются.
- Добавлены автоматические тесты API-клиента мастера и расширен изолированный интеграционный сценарий активации.
- Проверены 214 .NET-тестов, 25 веб-тестов и 21 изолированная PostgreSQL-проверка выдачи/просмотра/активации кода; Release-сборка без ошибок и предупреждений.
- Собран локальный EXE 1.1.0: 37 261 208 байт, SHA-256 `16AB8612074788D43E98A0966A32F665CE195C94B8926E7E1FDF29228F9FE91C`. Цифровая подпись пока отсутствует.
- Коммит `6955b32` вручную опубликован на Render; подтверждены `Live`, readiness/PostgreSQL `Healthy` и доступность `/api/devices/activation-preview`. Рабочий API совместим с EXE 1.1.0; вместе с обновлением опубликован интерфейс инцидентов.
