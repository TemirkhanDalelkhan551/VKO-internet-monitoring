# Веб-интерфейс инцидентов

Готов локально и включён в текущий снимок Git от 18.09.2026. На Render пока e130918 без нового экрана. Границы: [PROJECT_SNAPSHOT.md](PROJECT_SNAPSHOT.md).

Раздел в обзоре открывается боковой кнопкой «Инциденты». Из карточки школы «Инциденты этой школы» выбирает школу в фильтре.

## Возможности

- Список: номер/проблема, школа/линия/поставщик, статус, начало/длительность, ответственный.
- Фильтры школы, статуса и календарного периода. По умолчанию 30 дней; последний день включён полностью, часовой пояс браузера. Период относится к началу проблемы: старые открытые инциденты требуют расширения дат.
- До 1000 последних инцидентов с предупреждением при лимите. Неверные даты очищают список.
- Карточка: описание, источник, даты обнаружения/передачи/восстановления/закрытия, ответственный и история статусов/назначений/комментариев.
- Ручное создание: сохранённые школа/линия, тип, название, описание; начало устанавливает сервер. Уже активная проблема этой линии возвращает 409.
- Допустимые следующие статусы; восстановленный можно закрыть или вернуть в работу. Сервер повторно проверяет переход/конкуренцию.
- Назначение/снятие ответственного и комментарии по ролям. Ответственный — текстовое поле; выбора из пользователей пока нет.

| Роль | Создание | Статус/комментарии | Ответственный |
| --- | --- | --- | --- |
| Administrator / Regional | Да | Да | Да |
| School | Своя школа | Просмотр | Просмотр |
| Provider | Нет | Свои линии | Просмотр |
| District | Нет | Просмотр | Просмотр |

Область проверяет API. Actor задаёт сервер независимо от клиента; текст не исполняется как HTML. Выход очищает страницу, версии запросов/сессии защищают от поздних ответов. Обновление обзора сохраняет черновики; карточка обновляется отдельно. При записи формы блокируются, ошибка сохраняет текст.

Браузер: создание, назначение, комментарий, передача/работа поставщика, readonly School/District, переход из школы, пустой статус, неверные даты, черновик при обновлении, безопасный текст, выход и 390 px. Модель проверяет роли/переходы/нулевую длительность. verify-web-incidents.ps1: 25 проверок полного цикла, чужих объектов, автора и дат.

```powershell
dotnet publish src/VkoMonitoring.Api -c Release -o artifacts/api-incidents-test
./scripts/start-web-test-fixtures.ps1 -PublishDirectory artifacts/api-incidents-test -Port 5098
./scripts/verify-web-incidents.ps1 -BaseUrl http://localhost:5098
```

Только отдельная local fixture, не рабочая БД. После тестов остановить test API по сохранённому PID с проверкой command line. Обращение/AI, вложения и уведомления не входят в этот этап.
