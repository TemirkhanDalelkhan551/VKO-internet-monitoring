Контрольная точка исходников, документации и воспроизводимых проверок. Он проверяет восстановление активации, отказ чужой машине, жизненный цикл и отзыв токена, а также пять ролей и исправленный ответ `403` вместо серверной ошибки. Специализированные веб-сценарии предыдущего релиза остаются воспроизводимыми; UI жизненного цикла дополнительно проверен в браузере на локальной fixture. Исправление входа в рейтинг включено в успешно опубликованный `0c4ff6e`; после деплоя требуется проверить экран под пользовательской сессией.

```powershell
dotnet test VkoInternetMonitoring.sln -c Release
dotnet build VkoInternetMonitoring.sln -c Release
node --test tests/web/*.test.mjs
docker build -f src/VkoMonitoring.Api/Dockerfile -t vko-api:snapshot .
pwsh -NoProfile -File scripts/verify-api-integration.ps1 -ApiPort 5084
```

Веб-сценарии: опубликовать API в отдельный artifacts/api-test, запустить start-web-test-fixtures.ps1 с этим каталогом и свободным портом, затем нужный verify-скрипт с тем же BaseUrl. Для каждой проверки использовать свежую fixture; остановить именно её PID после проверки. БД должны быть local vko_web_*/vko_verify_*, не рабочая vko_monitoring и не Render. Тестовые пароли: USER_ACCESS_TESTING.md. Приватные логи/базы/резервные копии и EXE остаются вне Git.
