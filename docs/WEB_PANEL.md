# Веб-панель мониторинга

Состояние: 18.09.2026. Интерфейс обслуживается самим API из wwwroot, без отдельного сервера и npm-сборки. Публичный адрес: https://vko-internet-monitoring-api.onrender.com/ . Точные границы исходников и деплоя: [PROJECT_SNAPSHOT.md](PROJECT_SNAPSHOT.md).

## Реализованные экраны

- Вход/выход и обзор доступных школ. Качество, свежесть замера и присутствие агента независимы; основная и резервные линии отображаются отдельно.
- Поиск школы/района/поставщика, фильтры района/статуса/поставщика/подключения. Карта использует те же условия.
- [Карточка школы](WEB_SCHOOL_HISTORY.md): контакты, договоры, устройства, пять графиков, история и итоги календарного периода.
- [Общая аналитика и CSV/XLSX](WEB_ANALYTICS_REPORTS.md): период, школа/компьютеры, столбцы, состояние соединения.
- [Карта](WEB_MAP.md): координаты, цвета, пять метрик и переход в карточку. Школы без координат не получают вымышленных точек.
- [Справочники](WEB_DIRECTORY.md): школа, контакты, линия и договор для Administrator/Regional.
- [Коды активации](WEB_ACTIVATION.md): выбор школы/линии, срок, получение и копирование одноразового кода.
- [Инциденты](WEB_INCIDENTS.md): список/карточка, фильтры, ручное создание, назначение, комментарии, статусы и история. Экран опубликован на Render в `6955b32`.

## Авторизация и обновление

Вход: /api/auth/login, текущий пользователь: /api/auth/me. Bearer-токен только в памяти: перезагрузка требует нового входа. Выход отзывает сессию; 401 очищает страницу и возвращает вход. Пароли/токены/коды не сохраняются в URL или localStorage/sessionStorage. Права проверяет API до чтения/агрегации и изменения; скрытие кнопок не заменяет проверку.

Ручное обновление и автообновление раз в минуту на видимой странице. Черновики форм сохраняются при обновлении списка; карточка инцидента обновляется отдельно. Аналитика и экспорт имеют собственные условия. На телефоне таблицы прокручиваются внутри контейнера; формы проверены при 390 px. Пользовательский текст безопасно выводится как текст; Leaflet поставляется локально, CSP запрещает внешние скрипты и inline-скрипты.

UI инцидентов опубликован. Остаются веб-экраны пользователей/аудита, расписание/пороги, уведомления, сводки районов/поставщиков, обращение/AI и PDF. Работу второго компьютера пользователь принял 19.09.2026 без повторной полевой проверки. Проверки и синтетические аккаунты: [USER_ACCESS_TESTING.md](USER_ACCESS_TESTING.md).
