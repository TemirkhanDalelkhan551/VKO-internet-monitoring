# Веб-панель: карточка школы и история

Дата этапа: 18.09.2026. Актуальное состояние проекта: [PROJECT_SNAPSHOT.md](PROJECT_SNAPSHOT.md). В карточке также доступны контакты, реквизиты договоров и переход «Инциденты этой школы» (последний переход — в текущем локальном этапе).

Из обзора школ кнопка «Открыть карточку» открывает доступные пользователю линии, устройства, итоги школы и историю выбранного устройства. Название школы по-прежнему раскрывает линии непосредственно в списке.

Периоды: сегодня, последние 7/30 календарных дней либо свои даты. Даты интерпретируются в часовом поясе браузера, последний день включён целиком; API получает UTC-границы с исключающей верхней границей. В карточке указаны применённые даты. Выбор периода меняет статистику и историю, текущие показатели линий остаются текущими.

Итоги школы: средние, минимальные и максимальные Download/Upload/Ping, количество и доля проблемных замеров. Аналитика охватывает все доступные пользователю линии школы; графики и таблица относятся только к выбранному устройству. Доля замеров без потери соединения не является непрерывным uptime.

Пять SVG-графиков не требуют внешних библиотек и совместимы с CSP. Замеры сортируются по времени; null/Offline разрывают серию, ноль сохраняется. Точки не утверждают наличие непрерывного измерения между ними. История загружает не более 1000 последних замеров за период и показывает предупреждение при достижении лимита. Таблица содержит последние 200 загруженных замеров; графики — все загруженные.

При смене школы/периода/устройства прежние запросы отменяются. Версия запроса и версия сессии не позволяют запоздавшему ответу вернуть данные после выхода. При ошибке загрузки прежние показатели не выдаются за новый период. 401 возвращает на вход и очищает приватный DOM; токен хранится только в памяти страницы. Разграничение доступа выполняется API, в том числе до агрегирования аналитики.

Исторические проверки этапа карточки (актуальные счётчики — в PROJECT_SNAPSHOT.md):
- 161 тест .NET, 16 тестов веб-моделей; Release без ошибок и предупреждений.
- Linux Docker-сборка штатным Dockerfile Render.
- Браузер: Administrator/School/District/Regional/Provider; поставщик видит только свой канал и устройство, район/школа только свою организацию.
- История и пять графиков, Offline с пустыми метриками, нулевые потери пакетов, смена устройства, пустой период/школа, неверный диапазон, возврат к списку, выход, серверная блокировка с отзывом сессии.
- Широкий экран и мобильная ширина 390 px, таблицы прокручиваются внутри карточки.
