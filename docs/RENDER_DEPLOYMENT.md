# Развёртывание API на Render

В репозитории находится Blueprint `render.yaml`. Он создаёт два бесплатных ресурса
в регионе Frankfurt:

- `vko-internet-monitoring-api` — публичный Docker Web Service;
- `vko-internet-monitoring-db` — закрытая PostgreSQL 17 без публичного доступа.

## Первое развёртывание

1. Войдите в Render через GitHub.
2. Выберите **New → Blueprint**.
3. Подключите репозиторий `TemirkhanDalelkhan551/VKO-internet-monitoring`.
4. Оставьте путь Blueprint равным `render.yaml` и нажмите **Deploy Blueprint**.
5. Дождитесь, пока база и Web Service получат статус `Live`.
6. Откройте `https://<имя-сервиса>.onrender.com/health/ready`.

Ожидаемый HTTP-статус — `200`, а поле `status` должно быть `Healthy` или
`Degraded`. `Unavailable` означает, что API не может подключиться к PostgreSQL.

## Доступ администратора и перенос базы

В Blueprint общий `X-Admin-Token` отключён: `MonitoringApi__EnableLegacyAdminToken=false`.
Случайный `MonitoringApi__AdminToken` нужен только для проверки конфигурации старта,
но не предоставляет административного доступа. Веб-панель использует личные сессии.

До первого старта API импортируйте копию локальной PostgreSQL-базы, подготовленную
через `pg_dump --no-owner --no-privileges`. Не переносите активные `user_sessions`.
Пароль администратора остаётся прежним, в базу переносится только его хэш.
Резервная копия и секреты не должны попадать в Git или Docker-образ.

Для показа 22.09.2026 бесплатной базы с лимитом 30 дней достаточно. После показа
сохраните резервную копию до истечения срока. API и база должны находиться в одном
регионе; доступ базы извне открывайте только для конкретного IP на время импорта.
Автоматический деплой выключен, чтобы случайное изменение Git не прервало показ.

## Подключение агента

В мастере активации укажите публичный адрес Web Service с `https://`, без пути
`/health`. Например:

```text
https://vko-internet-monitoring-api.onrender.com
```

Сначала через административный API зарегистрируйте школу и линию, затем создайте
одноразовый код активации. Мастер использует этот код один раз и сохранит
индивидуальный токен устройства через Windows DPAPI.

## Ограничения бесплатного стенда

- Web Service засыпает после периода отсутствия входящих запросов, поэтому первый
  запрос может выполняться около минуты.
- Бесплатная PostgreSQL действует 30 дней и не имеет резервного копирования.
- Перед презентацией откройте `/health/ready` и убедитесь, что сервис проснулся.
- Не храните единственную копию важных данных в бесплатной базе.

Локальный запуск остаётся без изменений: `docker-compose.yml` поднимает только
PostgreSQL, а API запускается через `dotnet run`.
