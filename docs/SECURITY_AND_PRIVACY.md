# Безопасность и конфиденциальность

Техническое состояние на 18.09.2026: [PROJECT_SNAPSHOT.md](PROJECT_SNAPSHOT.md). Политика хранения ещё не завершена.

## Данные

Агент передаёт идентификаторы школы/линии/устройства/события, время, пять метрик, длительность, подключение, измерительный сервер, состояние/ошибку, версию и heartbeat. Внешний IP определяет API по соединению, значение клиента не принимается на доверии. Агент не собирает имя пользователя Windows, файлы, историю браузера и посещённые сайты.

Сервер хранит справочники, договорные реквизиты, необязательные ФИО/должность/телефон/email, пользователей/области доступа, инциденты/комментарии/историю. Контакты читаются в области разрешённой школы, изменяются Administrator/Regional; запросы входят в аудит. Контакты не включены в технические измерения и разрешённые CSV/XLSX-столбцы.

## Реализовано

- HTTPS Render со стандартной проверкой сертификата. Агент разрешает HTTP только для loopback.
- Токен привязан к школе/устройству/линии; блокировка/ротация отзывают доступ. Сервер хранит SHA-256-хэш, компьютер — DPAPI-файл с доступом SYSTEM/администраторов.
- Коды ограничены сроком, хэшируются и атомарно используются. Выдача защищена сессией/аудитом; код показывается только в ответе и памяти формы.
- PasswordHasher ASP.NET Core Identity для паролей, SHA-256 для сессий. Пять ролей проверяются до чтения/агрегации и изменения.
- Изменение пароля/роли/привязки и блокировка отзывают сессии. Есть лимиты, защита входа и последнего активного администратора.
- Аудит сохраняется до изменения; его отказ блокирует изменение. Автора ручных действий определяет сервер.
- EventId исключает повторную запись при повторной доставке, но не является криптографической подписью запроса.
- Диагностика не раскрывает внутренние ошибки/строки подключения. Авторизованные ответы no-store. UI не хранит секреты в URL/localStorage/sessionStorage; выход очищает данные.
- Пользовательский текст выводится безопасными DOM-узлами; экспорт защищает текст от исполнения формул. CSP ограничивает скрипты самим сервером, картинки — настроенным источником карты.
- PostgreSQL Render закрыта для внешних соединений; legacy X-Admin-Token отключён. Тестовые аккаунты отделены от рабочей базы.

Подложка карты загружается с внешнего tile-сервера (по умолчанию OpenStreetMap): браузер передаёт обычные сетевые данные и номера тайлов. Названия/контакты не добавляются в URL тайлов. Выбор подложки нужно учесть в политике сервиса.

## Остаётся

Сроки хранения измерений/IP/контактов/комментариев/аудита и процедура очистки; внешнее зашифрованное хранение резервных копий; длительные/нагрузочные тесты; шифрование локальной очереди; оценка дополнительной защиты при компрометации токена; фактическая подпись EXE доверенным сертификатом; проверка дополнительных редакций Windows; централизованные логи/метрики. API-аудит не заменяет мониторинг инфраструктуры. Пользователи, аудит, реестр/отзыв кодов, удалённая конфигурация и жизненный цикл устройств реализованы; автоматические обновления ещё отсутствуют.

Реальные секреты и резервные копии не попадают в Git/снимок. web-test-only-2026 — исключительно синтетический local fixture, не рабочий пароль.
