# Временный публичный API через Cloudflare Tunnel

Cloudflare Quick Tunnel публикует локальный API через HTTPS без открытия портов
роутера и без публичного IP. API и PostgreSQL продолжают работать на ноутбуке.

## Запуск

Для запуска PostgreSQL, сборки API и Tunnel одной командой выполните из корня
проекта:

```powershell
.\scripts\start-public-demo.ps1
```

Сценарий сам поднимает PostgreSQL, собирает API, создаёт сильный локальный
админ-токен при первом запуске и запускает Quick Tunnel. Окно PowerShell нужно
оставить открытым.

Если PostgreSQL и API уже запущены отдельно, можно запустить только Tunnel:

```powershell
.\scripts\start-cloudflare-tunnel.ps1
```

1. Дождитесь адреса вида `https://random-words.trycloudflare.com`.
2. Не закрывайте это окно до окончания демонстрации.
3. Проверьте `<публичный-адрес>/health/ready` с телефона через мобильный интернет.

В мастере активации вводится только базовый публичный адрес, без `/health/ready`.
Мастер автоматически настроит API, Download и Upload endpoints.

API, опубликованный в интернет, обязан запускаться с сильным значением переменной
`MonitoringApi__AdminToken`. Сервер отклоняет пустые значения и демонстрационные
секреты с префиксом `CHANGE_ME`.

## Важные ограничения

- Quick Tunnel является временным: после перезапуска адрес изменится.
- Ноутбук, PostgreSQL, API и процесс `cloudflared` должны быть включены.
- Сон ноутбука и потеря интернета остановят публичный стенд.
- Скоростные endpoints ограничены двенадцатью запросами в минуту на источник.
- Административный токен и токены устройств нельзя публиковать или показывать на
  презентации.

Перед демонстрацией отключите сон ноутбука от сети, запустите туннель заранее и
проверьте его с внешней сети. Для постоянного URL потребуется именованный Tunnel,
Cloudflare-аккаунт и домен, управляемый через Cloudflare.
