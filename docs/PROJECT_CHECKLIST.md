# Чек-лист проекта: система автономного мониторинга интернета

Статусы:

- `[x]` — реализовано и проверено;
- `[~]` — реализовано частично или требует проверки в реальной среде;
- `[ ]` — ещё не реализовано.

## Текущее состояние

Работает сквозной прототип: установленная Windows-служба измеряет реальные показатели, отправляет heartbeat, сохраняет результат при недоступном API, повторяет отправку и доставляет запись после восстановления связи. API регистрирует устройства, проверяет их токены, сохраняет результаты в PostgreSQL и отдаёт школы, устройства, историю, статусы и базовую аналитику. Собраны графический мастер первичной активации и единый русскоязычный EXE-установщик. Мастер получает привязку устройства по одноразовому коду, сохраняет токен через Windows DPAPI и запускает службу.

На Render опубликованы вход, обзор, карточки школ, история и графики, аналитика и CSV/XLSX, карта, редактирование школ/контактов/линий/договоров и выдача кодов (коммит `e130918`). Интерфейс инцидентов готов и проверен локально, но ещё не опубликован. Пользователи, пять ролей ТЗ и аудит реализованы на уровне API. JSON — только локальный режим разработки; производственные функции требуют PostgreSQL.

Открыты административные веб-экраны пользователей/аудита, расписания и порогов, обращение/AI и уведомления, сводки районов/поставщиков и приёмка на другом ПК. Сводка проверок, установщика и границы текущего снимка — в [PROJECT_SNAPSHOT.md](PROJECT_SNAPSHOT.md). Исторические записи в конце отражают состояние на момент этапа, а не текущий статус.
