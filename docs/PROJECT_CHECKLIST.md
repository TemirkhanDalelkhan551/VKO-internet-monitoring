# Чек-лист проекта: система автономного мониторинга интернета

Дата фиксации: 18 сентября 2026 года.

Статусы:

- `[x]` — реализовано и проверено;

- `[ ]` — ещё не реализовано.

## Текущее состояние

Работает сквозной прототип: установленная Windows-служба измеряет реальные показатели, отправляет heartbeat, сохраняет результат при недоступном API, повторяет отправку и доставляет запись после восстановления связи. API регистрирует устройства, проверяет их токены, сохраняет результаты в PostgreSQL и отдаёт школы, устройства, историю, статусы и базовую аналитику. Собраны графический мастер первичной активации и единый русскоязычный EXE-установщик. Мастер получает привязку устройства по одноразовому коду, сохраняет токен через Windows DPAPI и запускает службу.

Вся система целиком пока не готова: ещё нет пользователей и ролей, редактирования настроек, ручного ведения инцидентов, экспорта и веб-интерфейса. JSON-хранилище сохранено только как локальный режим разработки.
