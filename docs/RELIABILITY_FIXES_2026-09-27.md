# Проверки надёжности 27 сентября 2026

Изменения подготовлены локально поверх c7bb388. Рабочая база Render не использовалась и не изменялась.

## Инциденты

Причина MeasurementServerUnavailable означает отсутствие достоверной оценки школьной линии. Такой замер сохраняется, но не открывает и не разрешает школьный инцидент, не заменяет latest evidence. Он прерывает последовательность проблемных и восстановительных замеров, включая условие длительности нарушения. После него нужны новые последовательные подтверждения. InternetUnavailable продолжает считаться проблемой линии.

Изменение не удаляет ранее созданные инциденты, не меняет агрегаты рейтинга и не реализует корреляцию массовых инфраструктурных ошибок. Эти вопросы остаются отдельными задачами.

## Восстановление активации

Старый использованный код в пределах 24 часов действителен только для активного незаблокированного устройства с той же школой и линией. Условия проверяются в preview, выборе кода и атомарном UPDATE устройства: параллельная блокировка или перепривязка не должны быть отменены восстановлением.

Новый одноразовый код администратора по-прежнему позволяет повторную настройку активного, в том числе заблокированного, устройства по сохранённому installation identifier. Device ID сохраняется, токен меняется, блокировка снимается, изменение записывается в историю.

Проверки покрывают отказ старого кода после блокировки и перепривязки, разрешённую повторную настройку новым кодом и сохранение идентификатора. Физическая переустановка EXE, конкурентный стресс-тест и сценарий повторной установки списанного/заменённого устройства в этом этапе не проверялись.

## Воспроизведение

Стандартный scripts/verify-api-integration.ps1 по умолчанию работает с Docker как раньше. Для установленной локальной PostgreSQL:

```powershell
# PGPASSWORD задаётся локально, не сохраняется в Git и не выводится.
./scripts/verify-api-integration.ps1 -PsqlPath 'C:/Program Files/PostgreSQL/18/bin/psql.exe' -PostgresUser vko_local
```

Разрешён только loopback-хост. Скрипт создаёт отдельную vko_verify_* базу и сохраняет её для расследования; не принимает имя рабочей базы. Для подключения по умолчанию используется порт 55432. PostgreSQL должна быть запущена, у тестового пользователя должны быть права создания базы.

Результаты: 248/248 .NET, 184/184 API, включая 18 новых проверок двух исправлений. Новые API-проверки выполнены на PostgreSQL 18; Docker/PostgreSQL 17 в этом сеансе не запускался.
